# Regression ledger

Every bug found by CI, by a tester or by the round-trip matrix gets a row here and a permanent test that fails if it comes back.
A row has: the date it was found, what a person saw, the root cause, the pull request that fixed it, and the test that guards it
(`tests/<file>.py::<Class>.<method>`; `tests/test_roundtrip_ledger.py` fails when a named guard does not exist).
How to add one: [TESTING.md](TESTING.md#the-ledger).
